# KnowledgeBase Builder

Mind map + notes + research + quizzes + AI learning — single-page web app.

## GitHub Pages par chalane ke steps
1. GitHub par new repository banao (Public).
2. Is zip ki saari files upload karo (Add file → Upload files). `index.html` root me honi chahiye.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
4. 1-2 minute baad link milega: `https://<username>.github.io/<repo-name>/`

Note: API key code me mat daalo agar repo Public hai.
